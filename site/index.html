Hire and drive agents from the page.

Press Hire, pick an agent, a folder, a sandbox or an ssh box, and a first prompt. A worker walks in, and its desk opens the agent's own TUI in a real terminal, or a chat with approvals as buttons.

  • A real terminal

    The agent's own TUI, live, with a prompt box, Interrupt and Stop.

  • Chat, with approvals

    Replies, tool calls and approvals as buttons, for Claude Code, Codex and opencode.

  • Here, or there

    This Mac, a new or running Daytona, Vercel or Railway sandbox, or an ssh box.

  • Locked by default

    Watching needs nothing. Driving needs a browser unlocked with a one-time link.

How it works

One command. Nothing to configure.

  1. 01

    Run it

    $ npx @pvgomes/agent-visualizer
# or a busy simulated office
$ npx @pvgomes/agent-visualizer --demo

    Node 18+. It opens 127.0.0.1:4747.

  2. 02

    Start an agent

    # in another terminal
$ claude

    It walks in the moment it starts, and back to the lift when it quits.

  3. 03

    Let agents talk back optional

    # MCP server + skill, every agent
$ npx @pvgomes/agent-visualizer install

    --dry-run shows the exact diff first; uninstall puts every file back.

FAQ

Questions

Does it send my code anywhere?

No. What reaches the browser is an action and a file name, like “Edit auth.ts” or “$ npm test”. The server binds 127.0.0.1, there is no telemetry and no CDN, and it works offline. The only calls out are to the sandbox platforms and ssh boxes you're logged in to or configured.

Do I have to set anything up?

No. Run npx @pvgomes/agent-visualizer with Node 18 or newer and start an agent in another terminal. Each agent's transcripts are read from their usual folder.

Which agents does it watch?

Claude Code, Codex, Command Code, opencode, Cursor (the editor and cursor-agent), GitHub Copilot (VS Code and the Copilot CLI), Droid, Qwen Code and Gemini CLI. All but Gemini CLI are tested against real transcripts; Cursor records no tool results, so it can't show a pass or a fail.

Does it touch my agents' files?

Watching is read-only. Only npx @pvgomes/agent-visualizer install touches configs, when you ask: --dry-run shows the exact diff, every file is backed up first, and uninstall puts them all back.

Is the office on this page real?

Yes. It's the same scene the CLI serves, driven by the same --demo simulator, running in your browser. Nothing on this page reads your agents; every worker here is invented. The small views further down are cut from that same office, live.

What does it cost?

Nothing. Sandboxes you watch or hire bill on your own platform account, as they always do.
